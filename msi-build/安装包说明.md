# DeepSeek Harness 安装包（MSI + 引导 EXE）说明

## 交付物

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| **`DeepSeekHarnessSetup.exe`**（发给同事） | ~31 MB | 一键安装包：自动装 Node.js（如缺）→ 装 DeepSeek Harness → 建桌面/开始菜单图标 |
| `DeepSeekHarnessSetup.msi` | 64 KB | 内层 MSI（不含 Node，需先装 Node） |
| `payload\` | — | 安装内容：插件包（dsh-desktop-launcher）+ PowerShell 引擎 + 启动器 |
| `build-msi.ps1` / `generate-wxs.ps1` / `Product.wxs` / `Bundle.wxs` | — | 重建脚本与 WiX 源 |

## 安装流程（同事的操作）

1. 双击 `DeepSeekHarnessSetup.exe`（未签名的安装包会有 SmartScreen 提示 → 点「更多信息 → 仍要运行」）
2. 按向导下一步（会看到 MIT 许可页）
3. 若本机没有 Node.js，会**静默安装 Node.js 24 LTS**（几分钟）
4. 装完自动生成：**桌面「DeepSeek Harness」图标** + 开始菜单快捷方式
5. **第一次双击图标**：自动完成配置（需要联网）——
   - 全局安装 `@deepseek-ai/dsh`
   - 把内置的 `dsh-desktop-launcher` 插件注册进 web profile（设置页出现「Desktop Shortcut」）
   - 生成智能启动器（端口检查 + 自动打开浏览器 + 任务栏固定提示）
6. 之后每次双击：启动服务 → 自动打开浏览器 `http://127.0.0.1:3080`；关窗即停服

## 卸载

控制面板 → 程序 → 卸载 DeepSeek Harness。Node.js 不会被卸载（保留给你其他用途）。

## 已知注意点

- **未签名**：SmartScreen 会提示「未知发布者」，点「仍要运行」即可。若想消除提示，需要代码签名证书（收费，或 Azure 信任签名测试证书）。
- **首次运行需联网**：npm 安装 dsh + 注册插件需要网络（中国大陆网络建议在同事机器上先配置 npm 镜像）。
- **装机时间**：全新机器 ≈ Node 安装 2-5 分钟 + 首次运行配置 1-3 分钟。
- 安装目录：`%ProgramFiles%\DeepSeek Harness\`（含 plugin、engine、DeepSeek Harness.cmd）。

## 重新构建

```powershell
cd "E:\My Documents\DskHarness-PC\msi-build"
.\build-msi.ps1
```

依赖（已就绪）：WiX v4.0.6（nuget 解包于 `nuget-wix.4.0.6\`，扩展注册于 `~/.wix/extensions`）、Node MSI（`downloads\node-v24.19.0-x64.msi`）。GUID 持久化在 `guids.txt`（升级安装保持稳定）。

## 关于 WiX 版本的选择

- 用 **WiX v4.0.6**（MIT 协议，免费）而非 v7（v7 引入了 OSMF 维护费协议，商用需付费）。若未来想升级到 v7，需先接受其 EULA。
